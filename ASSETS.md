# Debug Arena — Assets

The first UI slice uses a generated-by-code visual system rather than external image files: a dark code-lab palette, lime debug signal color, blue ambient lighting, and monospace code panels. No large image assets are required for the current product slice.

Future art direction: if the game grows an onboarding illustration or mascot, use a restrained technical editorial style with charcoal background, lime highlights, and translucent blueprint geometry.
