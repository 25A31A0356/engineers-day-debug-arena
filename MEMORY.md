# Debug Arena — Memory

- The first version is intentionally client-only and local-demo friendly.
- Leaderboard entries are React state; refreshing resets the demo data.
- Roll numbers are uppercased and must be at least four characters.
- Question 1 is a confidence-building 'already correct' warm-up.
- The game uses 10 questions and a 15-minute countdown.
- Score weights are Easy 70, Medium 100, Hard 140 with an additional time bonus on completion.
- No server code was changed.
